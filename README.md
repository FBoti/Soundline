# Soundline
Wind and brass band management: events with RSVP, sheet music library and photo gallery.

A Soundline egy menedzsment rendszer fúvós- és rézfúvós zenekaroknak: események (próbák, fellépések) kezelése visszajelzéssel, kottaállomány és élménygaléria egy helyen, tagoknak és karnagynak.
